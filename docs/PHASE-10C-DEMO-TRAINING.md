# Phase 10C - Demo Mode and Training Portal

## Public demo

The `/demo` route is a frontend-only product demonstration. It uses local React state and static sample data for physiotherapy, pet grooming and car detailing scenarios.

Security boundaries:

- no authentication is required;
- no Supabase client is imported;
- no real owner or customer records are read;
- no action is saved or sent;
- reset returns the workspace to its original local state;
- protected-action language explains that confirmation is required in the real product.

## Owner Training Portal

The authenticated `/dashboard/training` route provides:

- searchable and filterable guide catalog;
- 12 essential owner workflows;
- localized interface in EN, EL, DE, ES and TR;
- 60 generated PDF guides (12 per active language);
- local-only completion progress scoped by business ID;
- direct links to the related Velliqo workspace;
- quick access to Velliqo AI for additional guidance.

Training progress is convenience data only and is stored in `localStorage`. It is not a security control and is never written to business tables.

## PDF generation

The PDFs are generated by:

```bash
python scripts/generate-training-pdfs.py
```

The generated files are stored under:

```text
public/training/guides/<language>/<guide>.pdf
```

## Validation

```bash
npm run demo-training:check
npm run translations:check
npm run typecheck
npm run build
```

The Phase 10C validator confirms routes, navigation, demo isolation, local progress storage, all localized PDF files and the required translation keys.
